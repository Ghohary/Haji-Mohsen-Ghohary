# NOIR ÉLÉGANCE - Luxury Evening Dresses Website

A world-class, mobile-first luxury evening dresses website featuring elegant design, smooth animations, and premium user experience.

## Features

### Design & Aesthetics
- **Luxury Brand Identity**: Elegant typography using Cormorant Garamond and Montserrat fonts
- **Premium Color Scheme**: Gold (#d4af37), black, and white for a sophisticated look
- **Mobile-First Responsive Design**: Optimized for all devices from mobile to desktop
- **Smooth Animations**: Fade-in effects, parallax scrolling, and reveal animations

### Key Sections

1. **Hero Section**
   - Full-screen elegant hero with gradient background
   - Animated scroll indicator
   - Call-to-action button

2. **Product Collection**
   - Filterable product grid (All Dresses, Evening Gowns, Cocktail, Ball Gowns)
   - 6 featured dresses with gradient placeholders
   - Product badges (New, Featured, Trending)
   - Hover effects with smooth transitions
   - Detailed product modals with specifications

3. **About Section**
   - Brand story and craftsmanship details
   - Statistics showcase (500+ creations, 38 years, 100% handcrafted)
   - Image gallery placeholder

4. **Testimonials**
   - Customer reviews with 5-star ratings
   - Dark background for contrast
   - Responsive grid layout

5. **Contact Section**
   - Contact information (location, phone, email)
   - Consultation booking form
   - Form validation

6. **Newsletter**
   - Email subscription form
   - Elegant dark theme

7. **Footer**
   - Quick links navigation
   - Customer care links
   - Social media links
   - Copyright information

### Technical Features

#### Mobile Optimization
- Mobile-first CSS architecture
- Touch-friendly navigation with hamburger menu
- Optimized touch interactions for product cards
- Responsive images with aspect ratio containers
- Fast loading with minimal dependencies

#### Performance
- Pure vanilla JavaScript (no framework overhead)
- CSS animations using GPU acceleration
- Intersection Observer API for scroll animations
- Lazy loading ready for images
- Throttled scroll events using requestAnimationFrame
- Reduced motion support for accessibility

#### Interactivity
- Smooth scroll navigation
- Mobile hamburger menu with slide-in animation
- Product filtering with smooth transitions
- Modal dialogs for product details
- Form submissions with success messages
- Touch gesture detection
- Parallax effects

#### Accessibility
- Semantic HTML5 structure
- ARIA labels for interactive elements
- Keyboard navigation support
- Reduced motion preference support
- High contrast ratios for readability

## Getting Started

Simply open `index.html` in a modern web browser to view the website. No build process or dependencies required.

For local development:
1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server: `python -m http.server 8000`
